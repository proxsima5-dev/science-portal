# 학습지 웹판(HTML) 만드는 규칙

학습지를 만들 때 인쇄용 HTML(`worksheet_<차시>.html`, 정답판 `_key`)과 함께 이 규칙대로 HTML 파일 하나를 더 만든다. 인쇄용 PDF는 선생님이 인쇄용 HTML을 브라우저에서 열어 [인쇄 → PDF로 저장]으로 만든다.
이 HTML은 정답이 들어 있으므로 **저장소에 넣지 않고** `../웹학습지/`에 둔다. 선생님이 관리 화면 → 수업 시작 → 차시 창 → [학습지 올리기]로 올린다(Claude는 올리는 방법만 안내).
포털이 파일을 읽어 학생 화면(쪽마다 넘기며 입력)으로 바꾸고, 정답은 서버에만 저장한다.

## 파일

- 파일 이름: `worksheet_<차시>_web.html` (예: `worksheet_611_web.html`)
- 내용은 인쇄용 학습지와 같다. 단, **정답을 칸 안에 써 넣은 정답판**으로 만든다.
- 스타일(CSS)·스크립트는 넣지 않아도 된다. 포털이 모양을 입힌다. 그림은 `<img src="data:...">`로 넣는다.

## 쪽 나누기

- 수업자료 한 쪽에 해당하는 내용을 `<section class="page">` 하나로 묶는다.
- `data-slide`: 수업자료 쪽 번호(필수). `data-title`: 그 쪽 제목(수업자료와 같게).
- 학습지 칸이 없는 수업자료 쪽은 만들지 않는다.

```html
<section class="page" data-slide="4" data-title="연필 양 끝 누르기">
  ...
</section>
```

## 칸 종류

| 종류 | 쓰는 법 | 채점 |
|---|---|---|
| 단어 빈칸 | `<span class="bl">정답</span>` | 정답과 같아야 함 (띄어쓰기·영문 대소문자 무시) |
| 허용 답 | `<span class="bl" data-alt="많아지고\|증가하고">늘어나고</span>` | 정답이나 허용 답 중 하나 |
| 순서 무관 빈칸 | `<span class="bl" data-any="a">화성</span>과 <span class="bl" data-any="a">목성</span>` | 같은 쪽에서 `data-any`가 같은 빈칸끼리는 순서를 바꿔 써도 맞음(같은 답 두 번은 하나만 맞음). 한 쪽에 묶음이 여럿이면 a, b, c… |
| 고르기 | `<span class="ox"><i class="ok">정답</i><i>오답</i></span>` | 정답을 골라야 함 |
| 여러 개 고르기 | `<span class="ox multi"><i class="ok">수성</i><i>목성</i><i class="ok">화성</i>…</span>` | 정답(ok)을 모두, 그리고 그것만 골라야 함(고른 순서 무관). 보기 글에 `\|`는 쓰지 않는다. 퀴즈 배틀·퀴즈 쇼 가져오기에는 안 들어감 |
| 고르기(예측처럼 정답 없음) | `<span class="ox"><i>보기1</i><i>보기2</i></span>` (`ok` 없음) | 아무거나 고르면 됨 |
| 부등호 | `<div class="ineq"><div>왼쪽</div><div class="box">&gt;</div><div>오른쪽</div></div>` | 맞는 부등호(`&lt;` `=` `&gt;`) |
| 서술 | `<div class="fill">예시 답안</div>` | 채우기만 하면 됨 (예시 답안은 학생에게 안 보임) |
| 시뮬레이션이 채우는 칸 | `.bl`·`.fill`에 `sim-in` 추가 (`<span class="bl sim-in">11</span>`) | 학생은 못 쓰고, 그 쪽 시뮬레이션이 `{type:'sim:answer', n, value}`로 n번째 칸을 채움 |
| 점 찍기(그래프) | `<div class="plot" data-x="부피 (mL)" … data-points="20,100\|10,200"></div>` (아래 '점 찍기 칸') | 정답 점을 모두, 틀린 점 없이 찍어야 함 |

- 문항 글은 칸과 같은 줄에 그대로 쓴다. 문항 번호는 `<span class="n">1</span>`, 소제목은 `<h3>`.
- 보기 상자는 `<div class="pool"><span class="tag">보기</span><b>바늘 · 누름못 · 칼</b></div>`처럼 지금 학습지와 같게.
- 표(`<table>`) 안에 빈칸을 넣어도 된다.

## 점 찍기 칸

표의 값을 학생이 그래프에 점으로 찍게 할 때 쓴다. 문항 글(`<div class="q">`) 아래에 따로 둔다.

```html
<div class="plot"
     data-x="부피 (mL)" data-y="압력 (kPa)"
     data-x-min="0" data-x-max="20" data-x-step="2"
     data-y-min="0" data-y-max="200" data-y-step="20"
     data-snap-x="1" data-snap-y="1"
     data-tol-x="0.5" data-tol-y="5"
     data-points="20,100|18,111.1|16,125|14,142.9|12,166.7|10,200"></div>
```

| 속성 | 뜻 | 없을 때 |
|---|---|---|
| `data-x`, `data-y` | 축 제목 | 경고 |
| `data-x-min` `data-x-max` `data-x-step` (y도 같게) | 축 범위와 눈금 간격. 수업자료 그래프와 같게 | 경고, 0~10 눈금 1로 그림 |
| `data-snap-x`, `data-snap-y` | 학생이 찍은 점을 반올림하는 단위 | 눈금 간격의 1/10 |
| `data-tol-x`, `data-tol-y` | 허용 오차(±) | 눈금 간격의 1/4 |
| `data-points` | 정답 점 `x,y`를 `\|`로 나눔 | 경고, 점이 하나라도 있으면 맞음 |

- 학생 화면: 빈 곳을 누르면 점이 찍히고, 찍은 점을 다시 누르면 지워진다. [되돌리기] [모두 지우기].
- 채점: 정답 점마다 오차 안의 학생 점을 하나씩 짝짓는다. 정답 점이 모두 짝을 찾고, 짝 없는 학생 점이 없으면 맞음. 점이 없으면 빈 칸.
- 틀리면 학생이 찍은 점 중 짝 없는 점은 ×, 나머지는 ○로 바뀐다. 정답 점은 보여 주지 않는다.
- 미리보기 경고: `data-points`가 비었거나 읽을 수 없는 점·축 범위 밖 점이 있을 때, 축 범위·제목이 없을 때, `<div>`가 아닐 때.
- 정답 점 사이 간격은 허용 오차의 2배보다 넓게 둔다(짝짓기가 헷갈리지 않게).

## 시뮬레이션 넣기

수업자료 속 시뮬레이션을 학생이 학습지 그 쪽에서 직접 해 보게 할 때 쓴다. 채점과는 상관없다.

```html
<div class="sim" data-src="sims/611_bottle.html"></div>
```

- 시뮬레이션은 학습지 파일 안에 넣지 않는다(포털이 스크립트를 지운다). **따로 만든 HTML 파일**을 포털 저장소 `sims/` 폴더에 올리고, `data-src`에 그 주소를 쓴다.
- 파일 이름은 영어·숫자·`_`·`-`만 쓴다(한글 이름은 주소가 안 열리는 문제가 있다). 예: `611_particle_box.html`
- 시뮬레이션 파일은 수업자료 안의 시뮬레이션과 같은 엔진으로 만든다(화면·움직임이 같게).
- 학생 화면이 넓으면(1100px 이상) 시뮬레이션이 오른쪽 칸(칸이 모두 시뮬레이션이 채우면 아래 큰 칸)에 바로 뜨고, 좁으면 [시뮬레이션 열기] 버튼으로 나와 누를 때만 불러온다.
- 칸이 모두 시뮬레이션이 채우는 칸(`.sim-in`)인 문항(`.q`)은 학생 화면에서 숨긴다(시뮬레이션 안에 같은 문항이 있음). 그래도 학습지 파일에는 그 문항을 그대로 둔다(채점·인쇄판·수업자료 문항과 맞추기).
- 시뮬레이션 화면 틀은 `디자인_규칙.md`(검정 = 누르는 것·고른 것, 회색 상자). 예전 파란 시뮬레이션은 6절의 덮어쓰기 CSS를 넣는다.
- 학생 학습지는 수업 중에는 수업자료 쪽을 따라가고(학생이 못 넘김), 수업이 끝나면 모두 열린다. 그래서 `data-slide`는 수업자료 쪽 번호와 정확히 같아야 한다.

### 끝까지 해야 쓰기 (2026-11-02)

시뮬레이션이 있는 쪽은 그 쪽 시뮬레이션을 **끝까지 해야** 칸이 열린다(학생 화면 위에 안내 띠, 잠긴 칸을 누르면 알림).
그래서 새 시뮬레이션 파일은 부모 창에 아래 신호를 보내야 한다.

```js
const tell=d=>{if(window.parent!==window)window.parent.postMessage(d,'*');};
tell({type:'sim:gate'});                        // 열리자마자: "나는 끝 신호를 보낸다"
tell({type:'sim:progress',n:2,total:5});        // (있으면) 진행 — 안내 띠에 2 / 5로 보임
tell({type:'sim:done'});                        // 할 일을 다 했을 때: 그 쪽 칸이 열림
```

- 포털은 iframe 주소 끝에 `#ws=쪽번호`를 붙인다. 한 시뮬레이션을 여러 쪽에서 쓰면 이것으로 쪽마다 할 일을 정한다(예: `712_planet_data.html` 6·7쪽은 빈칸이 있는 행성 카드 보기, 8·9쪽은 그래프 끝까지 재생).
- 표를 한 줄씩 채우는 쪽: 시뮬레이션이 `tell({type:'sim:gate',parts:true})`로 알리고, 하나를 볼 때마다 `tell({type:'sim:part',label:'수성'})`을 보내면 첫 칸 글자가 `수성`인 표 줄의 칸이 바로 열린다(다 보면 `sim:done`).
- 단계형 모션(makeMotion)은 마지막 단계까지 재생하면 done.
- `sim:gate`를 보내지 않는 옛 시뮬레이션은 열고 3초 뒤 자동으로 열린다(잠기지 않음). 이미 답을 쓴 쪽, 제출한 쪽은 잠그지 않는다.
