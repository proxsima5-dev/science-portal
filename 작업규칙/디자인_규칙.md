# 디자인 규칙 (2026-11-05 새 디자인)

포털(관리·학생 화면), 수업자료 HTML, 시뮬레이션, 학습지 웹판이 모두 이 규칙을 따른다.
기준이 되는 실제 화면: 관리 화면(`teacher/index.html`, `assets/css/site.css` 맨 끝 '나' 블록), 학생 화면(`html.stu`, site.css '가' 블록), 수업자료 `lessons/721.html`.
예전 디자인(파란 강조색 `#0066CC`, SF Pro, 유리 카드, 1280×720 넘기는 슬라이드)은 더 쓰지 않는다.

## 1. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#FFFFFF` | 화면 바탕(배경 원·그라데이션 없음) |
| 큰 상자 | `#F7F7F7` | 카드·표를 담는 연회색 둥근 상자 |
| 상자 안 상자 | `#FFFFFF` | 큰 상자 안의 표·입력·보기 |
| 알약 | `#F0F0F0` (올리면 `#E6E6E6`) | 보조 단추, 고르기 보기, 칩 |
| 선 | `#ECECEC` · `#E3E3E3` | 표 줄, 목록 구분선 |
| 글자 | `#0D0D0D` | 본문·제목 |
| 보조 글자 | `#5D5D5D` | 설명, 부제 |
| 흐린 글자 | `#8A8A8A` | 머리말(eyebrow), 쪽 번호, 안내 |
| 맞음·끝남 | `#0F8A5F` / 바탕 `rgba(34,197,130,.14)` | 정답, 제출함, 완료 |
| 다시 | `#A23B0B` / 바탕 `rgba(255,122,69,.16)` | 틀림, 다시 |
| 밤하늘 | `#0E1326` (가운데 `#1E2747` → 가장자리 `#080B17`) | 별·우주 그림 바탕 |
| 그림 강조 | `#FFB340` | 그림 안에서 움직이는 대상(별 궤적 끝 등) |

**색 규칙**
- **검정 = 누르는 것·고른 것만.** 주요 단추, 고른 보기, 고른 탭, 지금 쪽.
- **초록 = 맞음·끝남.** 그 밖의 상태 표시(오늘, 진행 중, 진도 막대)는 회색.
- 그림 안의 색(지구, 밤하늘, 나무, 교과서 그림)은 교과서 색을 그대로 써도 된다. 화면 틀(단추·카드·글자)에만 위 규칙을 적용한다.
- 강조를 위해 파랑·보라 같은 두 번째 색을 넣지 않는다.

## 2. 글자

- 글꼴: **Noto Sans KR** 400 / 500 / 700 / 900 (Google Fonts). 숫자는 `font-variant-numeric: tabular-nums`.
- 큰 제목은 **900**, 자간 `-0.035em ~ -0.05em`. 본문은 400~500, 강조는 700.
- 크기(수업자료, 프로젝터 1280×720 기준)

| 자리 | 크기 |
|---|---|
| 표지 제목 | `clamp(52px, 8.4vw, 112px)` |
| 단원 머리 제목(활동 1, 활동 2 …) | `clamp(46px, 7vw, 96px)` |
| 쪽 제목 | `clamp(26px, 2.7vw, 36px)` |
| 머리말(활동 이름) | 14px, 700, 흐린 글자 |
| 부제·용어 한 줄 | `clamp(15.5px, 1.3vw, 18px)`, 용어는 굵게 검정 |
| 표·문항 본문 | `clamp(16px, 1.45vw, 19.5px)` |

- 내용 글자를 상자에 맞추려고 줄이지 않는다. 상자를 키우거나 글을 줄인다.

## 3. 모양

- 큰 상자 모서리 **28px**, 카드 20~24px, 칩·단추 **알약(999px)**.
- 그림자·테두리·흐림을 쓰지 않는다. 예외: 떠 있는 것(위 메뉴, 창, 시뮬레이션 상자 가장자리 `0 0 0 1px #ECECEC`).
- 유리(반투명 + 흐림)는 **떠 있는 위 메뉴에만** 쓴다.
- 터치 영역은 40px 이상.

## 4. 단추·보기

| 종류 | 모양 |
|---|---|
| 주요 단추(제출, 수업 시작) | 검정 알약 `#0D0D0D`, 흰 글자 700 |
| 보조 단추(답 보기, 처음 위치로) | 연회색 알약 `#F0F0F0`, 검정 글자 |
| 고르기 보기 | 상자 안이면 흰 알약, 바탕 위면 연회색 알약 → 고르면 검정 |
| 맞음 / 틀림 | 초록 / 주황 바탕 + 글자로도 표시 |
| 잠긴 단추 | 연회색, 글자 `#8A8A8A` |

## 5. 수업자료 HTML (세로 스크롤, 721 기준)

`lessons/<차시>.html` 한 파일. 쪽을 넘기는 슬라이드가 아니라 세로로 이어지는 한 페이지다.

- **쪽**: `<section class="slide" data-title="쪽 제목" data-ws="학습지 구역">`. 쪽 수·순서는 학습지 웹판의 `data-slide`와 맞춘다. 스크롤할 때 화면 위쪽 45% 선을 지난 마지막 쪽에 `.active`를 붙인다(수업 모드가 이것으로 쪽 번호를 읽고, 학습지 진도·S·V·수업 따라가기가 동작).
- **위 메뉴**: 떠 있는 유리 알약. 왼쪽 차시·제목, 가운데 묶음(생각 열기·활동 1·활동 2…·정리), 오른쪽 '학습지 구역 n'과 'n / 12'(누르면 쪽 목록).
- **한 화면 쪽(`.screen`)**: 머리말 + 학습지 구역 칩 → 쪽 제목 → 용어 한 줄 → 시뮬레이션 상자(남은 높이 전부). ←/→로 오면 이 쪽이 한 화면에 딱 맞게 멈춘다.
- **단원 머리(`.chap`)**: 활동 묶음 앞에 아주 큰 제목 두 줄 + 한 문장(영상 소개 화면처럼).
- **표지**: 제목이 올라가며 사라지고, 밤하늘 창이 커지면서 노출 시간이 늘어 별 자취가 그려진다(스크롤에 맞춰).
- **시뮬레이션 상자**: 화면에 들어오며 0.94 → 1로 커지고 흐릿 → 선명. 가까이 올 때 불러오고 화면에서 벗어나면 `{type:'active', on:false}`로 멈춘다.
- **정리 쪽**: 큰 상자 안 흰 표, 오른쪽에 그림. `답 보기` 단추와 칸 누르기는 `Claude_Code_구현_안내.md` 3절 규칙 그대로(A 키도 답 보기).
- **정리 모션**: 스크롤에 맞춰 움직이는 정리 그림은 **시뮬레이션 뒤(정리 쪽 아래)에만** 둔다. 시뮬레이션 앞에 두면 예상 문항의 답을 먼저 보여 준다.
  - 탭형: 왼쪽 목록(지구의 자전 → 겉보기 운동 → …)이 스크롤마다 하나씩 펼쳐지고 오른쪽 그림이 바뀐다.
  - 가로 카드형: 옆으로 넘기는 카드마다 움직이는 그림(동·남·서·북 하늘).
- **키**: ←/→·Space·PageUp/Down 한 쪽씩, Home·End, Esc 쪽 목록, A 답 보기, F 전체 화면, 주소 `#7`이면 7쪽부터. 시뮬레이션 안에서 누른 키는 `simkey` 신호로 받는다.
- **그림**: 사진은 data URI로 파일 안에. 외부 이미지·CDN을 쓰지 않는다(글꼴만 Google Fonts).

## 6. 시뮬레이션

- 조작 안내 ①②③ 줄, 시뮬레이션 안 문항·[제출], 끝까지 해야 칸 열림 등 동작 규칙은 `수업설계_규칙.md` 10절과 `학습지_웹판_규칙.md`를 따른다.
- 새로 만들 때는 처음부터 위 색·단추 규칙으로 만든다.
- **잠긴 문항은 눌렀을 때 반드시 "무엇부터 할지" 알려 준다**(학생은 잠긴 1번부터 무의식적으로 누른다). 모든 시뮬레이션에 넣는다. 기준 구현은 `sims/721_earth_spin.html`의 `nudge()`와 `/* 잠긴 문항을 눌렀을 때 알려 주기 */` CSS를 그대로 복사한다.
  - 잠긴 문항에는 늘 `🔒 ○ ~하면 열려요` 줄이 보인다.
  - 누르면 ① 문항이 흔들리고 주황 테두리가 생기며, 잠금 줄 아래 `지금 할 일 → (안내 줄의 지금 단계)`가 4.5초 동안 보인다. ② 안내 줄에서 지금 단계가 노랗게 깜빡인다. ③ 시뮬레이션 위에 `🔒 아직 잠겨 있어요 · 먼저 ①부터 해 보세요` 알림이 뜬다. ④ 지금 단계 글에 `[단추 이름]`이 있으면 그 단추가, 없으면 시뮬레이션 칸이 주황으로 반짝인다.
  - 그래서 안내 줄 단계 글에는 누를 단추를 `[▶ 지구 돌리기]`처럼 대괄호로 실제 단추 이름과 똑같이 쓴다.

## 7. 학습지(학생 반 페이지)

- **수업 따라가기**: 수업 모드가 열려 있는 동안 학생 학습지는 수업자료의 지금 쪽을 저절로 보여 주고, 학생은 앞뒤로 넘기지 못한다. 학습지에 쓸 칸이 없는 쪽(표지·정리)은 '수업자료 n쪽 · 제목'과 "이 쪽은 학습지에 쓸 칸이 없어요" 카드.
- **수업 끝**: 수업자료가 마지막 쪽에 가거나 W를 누르면 모든 쪽이 열리고 마음대로 넘기며 덜 쓴 쪽을 쓴다.
- **같은 문항 두 번 보이지 않게**: 시뮬레이션이 있는 쪽에서 칸이 모두 시뮬레이션이 채우는 칸(`.sim-in`)인 문항은 학습지 위에 그리지 않는다(시뮬레이션 안에 같은 문항이 있음).

## 8. 하지 않는 것

- 카드·단추에 그림자나 테두리, 유리(위 메뉴 말고).
- 클릭으로 넘기는 단계 모션(속도·◀▶) — 직접 조작 시뮬레이션으로(`수업설계_규칙.md` 10절).
- 시뮬레이션 앞에 답을 보여 주는 스크롤 모션.
- 이모지 아이콘, 실존 캐릭터·로고.
