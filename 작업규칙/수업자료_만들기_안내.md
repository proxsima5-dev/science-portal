# 수업자료 만들기·크게 고치기 안내

선생님이 "○○차시 수업자료 만들어 줘", "○○차시 이 쪽을 바꿔 줘"라고 하면 이 순서대로 한다.

## 폴더

```
(작업 폴더)/
├─ science-portal/        이 저장소(공개). 수업자료 lessons/, 시뮬레이션 sims/
├─ 웹학습지/               worksheet_<차시>_web.html (정답판, 저장소에 넣지 않음)
├─ 수업재료/<차시>/        선생님이 넣는 교과서·지도서 PDF, 수업 PPT
└─ 초안/<차시>.md          수업 설계 초안
```

## 순서

1. 읽는 파일: `작업규칙/수업설계_규칙.md`, `작업규칙/모션그래픽_가이드.md`, `작업규칙/디자인_규칙.md`, `작업규칙/학습지_웹판_규칙.md`, 그리고 그 차시의 `../수업재료/<차시>/`만. 다른 차시·단원 자료는 열지 않는다. 수업재료가 없으면 먼저 넣어 달라고 한다.
   - **먼저 자료를 꺼낸다**(아래 '자료 꺼내기'). 그 뒤로는 PDF·PPT를 다시 열지 않고 `../수업재료/<차시>/자료추출/`의 글·그림만 읽는다. 교과서 쪽 그림(`교과서_쪽/p012.png`)을 직접 보고 그림 위치를 찾는다.
2. **새 차시면 초안부터.** `작업규칙/초안_템플릿.md` 모양으로 `../초안/<차시>.md`를 써서 보여 주고, 선생님이 좋다고 하면 만든다. 이미 있는 차시를 고치는 거면 바꿀 쪽과 내용만 정리해서 보여 준다.
3. 교과서와 다른 내용, 개념 오류, 쪽 번호 어긋남을 찾으면 임의로 고치지 말고 보고한다.
4. 만들 파일
   - 수업자료 `lessons/<차시>.html` — 새 차시일 때. **원래 있는 차시를 고칠 때는 `lessons/<차시>_my.html` 사본**(CLAUDE.md 3절). 시뮬레이션을 안에 품은 HTML 하나, 세로 스크롤 방식(`디자인_규칙.md` 5절, 기준 `lessons/721.html`). 안에 넣는 시뮬레이션은 base64(SIMS_B64)로 품는다.
   - 학생용 시뮬레이션 `sims/<차시>_<영어이름>.html` (원래 것을 고칠 때는 `_my` 사본)
   - 웹 학습지 `../웹학습지/worksheet_<차시>_web.html` (정답판, 저장소 밖)
   - 인쇄용 학습지가 필요하면 `../웹학습지/worksheet_<차시>.html`(정답 없음)·`_key.html`(정답) — 선생님이 브라우저에서 [인쇄 → PDF로 저장]
5. 답 공개: 쪽마다 `답 보기` 버튼(누를 때마다 다음 답 하나씩), 칸을 직접 눌러도 답을 보였다 숨김. 단어 빈칸(`.bl`)은 그 칸, 고르기(`.choice`)는 보기를 누르면 정답(`span.right`)이 켜지고 꺼진다. `lessons/721.html`의 답 보기 코드를 그대로 따른다.
6. 만든 뒤 검수: 1280×720에서 ←/→로 쪽마다 제목과 시뮬레이션이 한 화면에 들어오는지, 글자 넘침·잘림, 시뮬레이션 동작, 스크롤하면 `.slide.active`가 바뀌는지. 극단값(슬라이더 양 끝, 각도 0/90/180/270°)에서 라벨이 잘리지 않는지.
7. 다 되면 선생님께 안내:
   1. "올려 줘"라고 하면 GitHub에 올림 (2~10분 뒤 사이트 반영)
   2. 관리 화면 → 수업 시작 → 그 차시 창의 수업자료 주소를 `lessons/<파일 이름>.html`로 [저장] (새 차시면 [+ 차시 추가]부터)
   3. 같은 차시 창 → [학습지 올리기] → `웹학습지/worksheet_<차시>_web.html` → 미리보기 확인 → 저장
   4. 보드가 없으면 관리 화면 → 보드 → [+ 새 보드]

## 자료 꺼내기 (차시마다 한 번)

`../수업재료/<차시>/`의 PDF·PPT에서 글과 그림을 꺼내 `../수업재료/<차시>/자료추출/`에 둔다. 이미 있으면 건너뛴다. 도구는 `작업규칙/도구/`에 있다.

| 재료 | 맥 | 윈도우 |
|---|---|---|
| 교과서 PDF | `swift 작업규칙/도구/pdfdump.swift <pdf> <자료추출> 교과서 png` | `python 작업규칙/도구/pdfdump.py <pdf> <자료추출> 교과서 png` (처음 한 번 `python -m pip install pymupdf`) |
| 지도서 PDF | 위와 같고 이름만 `지도서`, `png`는 빼도 됨(글만) | 같음 |
| 수업 PPT(.pptx) | `python3 작업규칙/도구/pptdump.py <pptx> <자료추출> PPT` | `python 작업규칙/도구/pptdump.py <pptx> <자료추출> PPT` |

결과:
```
수업재료/<차시>/자료추출/
├─ 교과서_글.md   교과서_쪽/p001.png …   (쪽 그림 2배)
├─ 지도서_글.md
└─ PPT_글.md      PPT_그림/s03_image7.png …   (슬라이드 번호_원래 이름)
```

- 맥에서 `swift`가 없다고 나오면 `xcode-select --install`(뜨는 창에서 [설치]) 뒤 다시.
- PDF·PPT가 여러 개면 이름 뒤에 번호를 붙인다(`교과서2`). `.ppt`(옛 형식)는 PowerPoint·Keynote에서 `.pptx`로 저장해 달라고 한다.
- 지도서가 수백 쪽이면 그 차시 쪽만 읽는다(`지도서_글.md`에서 차시 제목으로 찾기).

### 그림 넣기

- **사진·그림 자리를 비워 두지 않는다.** 초안의 "사진 자리"는 모두 PPT 그림이나 교과서 쪽 그림을 오려 채운다. 못 찾은 것만 보고에 적는다.
- PPT 그림(`PPT_그림/`)이 원본 화질이라 먼저 쓴다. 없으면 교과서 쪽 그림을 오린다.
  - 맥: `sips --cropOffset <위> <왼쪽> -c <높이> <너비> 교과서_쪽/p012.png --out 그림.png` (픽셀, 쪽 그림을 먼저 열어 위치를 잰다)
  - 윈도우: `python 작업규칙/도구/pdfdump.py <pdf> <자료추출> 교과서 crop <쪽> <x0> <y0> <x1> <y1> 그림.png` (p012.png 픽셀 기준, 3배 해상도로 다시 그림)
- 오린 그림은 수업자료 안에 base64로 넣는다. 교과서 쪽 번호·글씨가 함께 잘려 들어오지 않았는지 본다.

## 웹 학습지를 다시 올리기 전에

처음 올리는 차시(서버에 그 차시 학습지가 없음)는 그대로 올리면 된다. 이미 올라가 있고 학생이 쓴 학습지는 칸 번호(f1, f2 …)가 바뀌면 답이 엉뚱한 칸으로 간다. 다시 올리기 전에 서버의 지금 칸 목록과 비교한다(Supabase 연결로).

```sql
select lesson_code, field_count, (select array_agg(k order by length(k), k) from jsonb_object_keys(key) k) as keys
from public.worksheets where lesson_code = '<차시>';
```

- 고친 파일의 칸이 서버 칸 목록과 앞에서부터 같아야 한다(새 칸은 맨 뒤에만). 다르면 올리지 말고 선생님께 알린다.
- 712·713은 원래 서버에서 몇 쪽만 따로 고쳐서 칸 번호가 파일 순서와 다를 수 있다(712는 f29~f31이 없고 f32가 있음, 713은 쪽 몇 개를 바꿔 끼움). 위 SQL의 칸 목록이 파일과 다르면 통째로 다시 올리지 않고, 꼭 고쳐야 하면 원래 포털 선생님과 먼저 상의하시라고 한다.

## 하지 않는 것

- 웹 학습지·정답 파일을 저장소에 넣기
- 원래 있는 `lessons/`·`sims/` 파일을 직접 고치기(사본으로)
- 게임 칸·게임 링크 넣기(CLAUDE.md 4절)
